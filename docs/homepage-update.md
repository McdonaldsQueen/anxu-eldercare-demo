# 首页调整与验收

本次在现有 LandingPage、品牌色和设计 tokens 基础上调整首页。收短首屏文案，增加生活照片流与留白段落，将原三端入口放到页面下方。没有修改三端页面、Store、OpenHex、Case、Safety Case 或关系绑定逻辑。

“开始体验”沿用原有角色切换与 `BrowserRouter` 路由，进入老人端；“自由探索”只滚动并聚焦下方入口，不改变当前地址。Vercel 通过 rewrites 支持三角色深层路径直接访问。

## Typography 与 CTA 细化（2026-09-19）

沿用四段内容、照片流和米白 / 深绿色体系，仅修改首页文字标记与样式：

- 移除所有首页 `<br>`；Hero、照片标题、Statement、入口标题和副文案按可用宽度自然换行，使用 `text-wrap: balance` 平衡多行文字。
- Hero 文案容器扩至 1180px；字号 `clamp(42px, 4.3vw, 64px)`，字重 650、行高 1.08。副文案 18px / 1.7，价值句 17px。
- 照片标题限制 900px，36–40px / 1.2；距照片约 42px，原无限滚动逻辑不变。
- Statement 合为完整一句“AI 不替代照护者，它让人的时间重新回到人身上。”，统一深绿色与 550 字重，40–44px / 1.25，宽度限制 1100px。
- 入口标题 32–36px，角色名称 20px，说明文字 16px。延续现有整块点击、内边距与轻微 hover。
- 主 CTA 仅文字，高 48px、水平 padding 26px、16px 字号、胶囊圆角；自由探索使用文字向下箭头，文字与箭头间隔 12px。CTA 之间桌面间距 32px，手机 24px。
- 小标签、照片暂停按钮、页脚统一至少 14px；手机正文为 17px，标题按比例缩放，不增加任何装饰元素。

1440px 实测：Hero 61.92px、照片标题 38.88px、Statement 43.2px、入口标题 36px；前三处均为一行。1280px 也保持一行，平板与手机自然换行。四种尺寸均无横向溢出，所有照片正常加载。

验收：81 项测试通过，production build 通过；键盘跳转、CTA / 三端入口、暂停与恢复、无缝循环及四种尺寸下的减少动态效果均已检查。
