# ADR 0002：访客会话与客户端流式超时

- 状态：已接受
- 日期：2026-09-16

## 决策

工作区密钥只保留在 Vercel Function；浏览器使用稳定 HttpOnly 访客 Cookie 换取 30 分钟短时令牌，并直接连接 OpenHex SSE。Agent 空闲超时显式设置为 300 秒，不通过 Vercel 代理长连接。

## 原因

直接 SSE 能保留 SDK 的流式、自动重连和会话恢复能力，也避免把 Agent 执行时长变成 Vercel Function 的执行时长问题。300 秒用于覆盖冷启动和子 Agent 长时间无事件场景。

## 后果

Vercel 日志只能观察令牌接口；Agent 阶段通过浏览器脱敏诊断定位。空闲超时后先同步历史，不能自动重发上一条消息。
